# Student Mental Health Score Prediction

A machine learning web application that predicts a student's mental health score based on their lifestyle, academic routine, stress level, and social media usage.

## 🚀 Live Demo

- **Frontend Application:** [Open Mental Health Predictor](https://mental-health-prediction-1-zr2y.onrender.com/)
- **GitHub Repository:** [View Source Code](https://github.com/surya999610/mental_health_prediction)

The frontend provides the interface for entering student information, while the FastAPI backend processes requests and returns predictions from the trained machine learning model.

## 📌 About the Project

This project explores how everyday habits and social media usage relate to students' mental health scores. Users can enter details about their daily routine and personal profile to receive a predicted score from a trained machine learning model.

I built the project using Python and Scikit-learn for machine learning, FastAPI for the backend API, and HTML, CSS, and JavaScript for the frontend. The application is deployed on Render.

## ✨ Features

- **Mental Health Score Prediction:** Generates a predicted score based on the submitted information.
- **12 Input Fields:** Collects student profile, academic, social media, lifestyle, and stress-related information.
- **Machine Learning Model:** Uses a trained Random Forest model for predictions.
- **REST API:** Connects the frontend to the machine learning model through FastAPI.
- **Input Validation:** Validates submitted data using Pydantic.
- **Web Interface:** Provides a simple interface for entering details and viewing prediction results.
- **Live Deployment:** Hosted on Render for online access.

## 📊 Input Features

The application uses the following information to generate a prediction:

- Age
- Gender
- Country
- Academic level
- Most-used social media platform
- Purpose of social media use
- Average daily social media usage hours
- Daily phone unlocks
- Daily study hours
- Daily physical activity hours
- Sleep hours per night
- Stress level

The model returns a `predicted_mental_health_score` based on these inputs.

## ⚙️ Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/surya999610/mental_health_prediction.git
cd mental_health_prediction
```

### 2. Create a virtual environment

```bash
py -m venv .venv
```

### 3. Activate the environment on Windows

```powershell
.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use Command Prompt and run:

```cmd
.venv\Scripts\activate.bat
```

### 4. Install dependencies

```bash
py -m pip install -r requirements.txt
```

### 5. Start the FastAPI server

```bash
py -m uvicorn main:app --reload
```

### 6. Open the application

The API will be available at:

- **FastAPI Backend:** [Open API](https://mental-health-prediction-2-sunh.onrender.com)
- **Interactive API Documentation:** [Swagger UI](https://mental-health-prediction-2-sunh.onrender.com/docs)

Open `index.html` in your browser to use the frontend. If you are running the frontend locally, make sure the API URL in `script.js` points to your local FastAPI server.

## 🔌 API Endpoint

### `POST /predict`

Accepts student information and returns a predicted mental health score.

The API validates the request, prepares the input data, passes it to the trained model, and returns the prediction.

Example response:

```json
{
  "predicted_mental_health_score": 7.25
}
```

*The score above is only an illustrative example, not a measured result from the model.*
